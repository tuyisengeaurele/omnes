# Brand assets

- `omnes-logo-motion.png`: primary mark, animated/motion variant source.
- `omnes-logo-speed-pin.png`: map-pin mark, used where a compact icon fits better than the full logo.

Both are aureolin on transparent. No dark-mode variant exists yet; until one is produced, place either mark on a bistre or neutral-dark surface rather than directly on an arbitrary background, since aureolin has very low contrast against light UI backgrounds (see the contrast note in `packages/config/tailwind/tokens.js`).
